# Quem sou eu?

Todo usuario tem um numero (UID). O sistema decide o que voce pode fazer por ele.

| Comando | O que faz |
| --- | --- |
| `whoami` | seu nome de usuario |
| `id` | seu UID, seu grupo principal e todos os grupos |
| `groups` | so os grupos |
